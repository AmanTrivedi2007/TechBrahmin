# ⚡ Tech Brahmin

> A personal portfolio to showcase my projects, skills, and work.

## 🚀 Tech Stack

- **Frontend:** React, Vite, CSS
- **Backend:** Python, FastAPI
- **Database:** MongoDB Atlas
- **Security:** SlowAPI (Rate Limiting)
- **Deployment:** Render

## ✨ Features

- 📂 Dynamic project showcase
- 🔍 Filter projects by category
- 📩 Contact form
- 🌗 Light and dark themes
- 🔒 API rate limiting
- 📱 Responsive design

## 💻 Run Locally

**1. Clone the repository**

```bash
git clone <your-repository-url>
cd Tech_Brahmin
```

**2. Start the backend**

```bash
cd Backend
pip install -r requirements.txt
uvicorn app:app --reload
```

**3. Start the frontend**

Open another terminal:

```bash
cd Frontend
npm install
npm run dev
```

> ⚙️ Configure your environment variables before running the application.

## 🌐 Deployment

Deployed using **Render**, with MongoDB Atlas for database hosting.
